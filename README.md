A GTA 6 meme about the 13-year wait since GTA V: a fan with a grey beard still sitting at the same desk, with make.fun's ghost keeping him company while he waits for GTA VI to finally arrive. The meme is posted on X from a public account; this repository hands in the post's address in POST.json, and main.ts copies it to /output for the gate.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
